# شطّب بيتك وأنت مطمّن مع الخزف السعودي
كتالوج تفاعلي ثلاثي الأبعاد لفريق المبيعات الخارجية (Outdoor Team).

- الموقع: `index.html` + `img/` + `data/` (يُنشر عبر GitHub Pages من الفرع main).
- المصدر وأدوات البناء: مجلد `src/` (المصدر الرئيسي `src/villa-src.html`، والبناء `src/scratchpad/build.py`).
- سجل العملاء: `src/customer_log_apps_script.gs` (Google Apps Script)، ورابطه يوضع في `src/scratchpad/track_url.txt`.
